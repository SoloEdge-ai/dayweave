| 本地化 | 简体中文、日语与英语界面，登录页和设置中的语言选择，使用当前语言的助手回复，以及经过校验的词条目录 |
| 助手 | 本地会话、服务商及模型选择、流式事件、真实业务工具、本地语音转写、自动保存的可编辑任务草稿、明确确认，以及可直达编排页的回执 |

| 设备 | 桌面工作区、手机响应式视图，以及常用操作可触控的 iPad 横屏与竖屏布局 |

## 第一版待集成验收

* **聊天和语音。** 从聊天入口验证每项工作区操作，包括首次配置服务商。在受支持的设备上验收麦克风录音，以及中文、日语和英语的转写质量。
* **个人局域网访问。** 开放 HTTPS 前，验证已获准的物理局域网设备可以连接，且公司 tailnet 无法通过 IPv4、IPv6、子网路由、代理或 Docker 转发访问服务。重启后重复检查。仍有适用路径未经验证时，只提供回环访问。

## 验证范围

后端自动化测试使用 SQLite 和服务商测试夹具。浏览器验收使用构建后的前端、真实认证与 HTTP 接口以及临时数据库，聊天模型由模拟服务提供。Playwright 使用 WebKit 在两种 iPad 方向验证音频上传转写、草稿编辑与确认、精确时间编辑、截止日期保留与撤销。提供音频文件后，同一组测试可以使用本地 Whisper。受信任 HTTPS 下的麦克风授权与录音、软键盘、屏幕旋转和 Apple Pencil 仍需在实体 iPad 上验证。

容器测试覆盖迁移、认证、本地模型服务、关联项目及资料、上传文件、设置与对话，并核对重启前后的状态。备份检查还会将数据恢复到新卷。运行命令见[项目说明](../README.zh-CN.md)。

服务商适配器和 ChatGPT 授权助手已实现。获得真实外部响应需要用户的 API Key 或 OAuth 同意。目录访问、推理权限及具体模型能力取决于账号。ChatGPT 官方登录还受应用接入资格和工作区策略约束。详见[服务商接入](AI_PROVIDERS.zh-CN.md)。

## 后续开发

* 根据分次执行或周期任务的实际使用情况，为同一任务增加多条执行安排。
* 用真实使用样例扩展自然语言日期表达及规划约束。
* 在实体 iPad 上验证原生键盘、辅助技术、分屏和屏幕旋转。
* 根据服务商发布的能力定义扩展模型覆盖范围。
* 增加用户可选择开启的元数据获取，并严格限制服务端出站请求。当前资料库保存链接和用户填写的元数据。
* 根据基础工作流的真实使用情况评估日历同步、主动通知、文档问答和字幕集成。
