# DayWeave 产品说明

[English](PRODUCT.md) · 简体中文 · [第一版设计与验收标准](V1_DESIGN.zh-CN.md)

织日是管理任务、项目、阅读与观看的个人工作区。第一版设计以聊天为主要入口。用户可以打字，也可以口述、校对转写文字后再发送。在聊天里确认创建的任务，与手动创建的任务出现在同一批视图中。

## 一天的使用流程

1. 输入标题记录任务，或在资料库保存链接。尚未指定日期或计划范围的任务进入收件箱。
2. 准备安排工作时，选择日期、时段或具体起止时间。截止日期单独记录。例如，周五到期的任务可以安排在周四下午。
3. 在首页查看重点、当天任务、阅读资料及提醒。此前计划但未完成的工作会单独显示，由用户决定何时重新安排。
4. 分别更新任务与关联资料的进度。观看同一视频的二十分钟内容，可以支撑多个学习目标。
5. 让助手查询或修改同一批记录。助手创建任务时会在对话中给出草稿，可以补充可选字段，刷新后继续编辑已自动保存的内容，然后确认或取消。确认后的卡片可以直接打开任务。其他重要变更也需要审阅；变更记录提供操作来源。

## 导航与录入

桌面布局把主要空间留给任务列表，导航连接首页、任务视图、项目、资料库和设置。助手既有独立页面，也可以从其他页面展开或收起。在 iPad 横屏和竖屏下，主要列表可以正常操作，常用动作可以直接点按。手机导航和编辑器按可用宽度布局。各设备共享数据及交互规则。

登录页和工作区设置提供简体中文、日语和英语。选定语言应用于导航、表单、任务草稿、操作反馈和助手的新回复。用户录入的内容保留原文。初始时区为 Asia/Hong_Kong，可在设置中选择其他 IANA 时区。操作及开发文档提供英文和简体中文版本。

## 拟议中的计划页

独立的 `/planner` 页面将待安排列表与当前计划周期放在一起。今天和明天显示单日日程，本周和下周使用完整的周一至周日日历，本月显示整月日历。日期格显示已安排的任务或数量。选择某一天即可查看该日详情。

尚未决定具体执行日期时，可将任务保留在某周或某月的待定日期列表中。指定日期或时刻会更新原任务。移回收件箱会清除计划安排并保留截止要求。计划变更会留下记录，并支持带状态检查的撤销。

## 验收流程

| 用户意图 | 可验证的结果 |
| --- | --- |
| 保存未指定日期的想法 | 收件箱出现记录，未指定的截止日期保持为空 |
| 请助手创建任务 | 聊天中出现可编辑草稿。编辑或取消不会创建任务。确认创建一条任务，回执可打开该任务 |
| 把任务改到明天 | 同一个任务 ID 出现在明天视图中，截止日期保持原值 |
| 将工作先安排到下周 | 任务出现在下周的待定日期列表，确定具体日期后会出现在对应日期的日历中 |
| 保存视频稍后观看 | 资料库有 URL 和明确的进度单位，并可关联已安排的观看任务 |
| 询问明天有哪些任务 | 助手查询本地记录，依据当前数据返回答案 |
| 标记任务完成 | 状态、完成时间、视图和变更记录一致 |
| 切换模型 | 请求使用新选的适配器，本地会话历史仍保留 |
| 重启容器 | 原有记录、文件和设置仍然可用 |

## 实施顺序

1. 先验收三种语言的聊天流程，包括接入服务商前的本地配置、基于数据库的工具和可编辑任务草稿。检查确认、取消和重试。
2. 将本地语音输入接入聊天框。验证转写文字可以在发送前校正，口述建任务也经过相同的草稿确认流程。
3. 将计划页、手动操作、项目与资料接到同一批记录上，验证日历边界、截止精度和撤销。
4. 使用真实服务商验证推理，并在具备资格时验证 ChatGPT 官方授权。在实体 iPad 上检查语音、键盘和屏幕旋转。
5. 发布前验证迁移、备份与恢复，并证明个人局域网 HTTPS 入口与公司 tailnet 隔离。
